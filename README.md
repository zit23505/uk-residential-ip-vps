## 原生、住宅、双ISP、机房IP，一段话说清

原生 IP 指 IP 段由英国本土 ISP 分配，归属地查出来是英国本地，不是机房托管段。住宅 IP 更进一步，IP 挂在英国家庭宽带运营商名下，平台看到的是"某个英国家庭在上网"。双 ISP 则是注册信息和路由归属分别对应两家英国本土 ISP，比单 ISP 更难被判成代理。机房 IP 就是反例——ASN 一查是云厂商，TikTok、BBC、亚马逊的风控专门盯这类段。

便宜的伦敦 VPS 给的是什么？LightNode 官方 FAQ 写得很坦白：每台英国 VPS 配"专用的英国本地静态 IP（**非英国原生IP**）"，起价 $7.71/月。这句话值得记住——**"英国 IP"和"英国原生住宅 IP"是两个东西**，前者几十块就能买到，后者才是账号运营场景真正要付钱的部分。

丽萨主机的说法是接入 Sky Telecom（天空电讯）这类英国本地宽带运营商的 IP 段，属全新 A 段，双 ISP 原生住宅属性。需要说清楚的是：这是商家和测评方的判定，公开路由证据并不完全支持。有第三方测评对一台机器做 traceroute，前四跳全部落在 AS174 cogentco.com 的伦敦节点上，测评者自己也写"cogent 全新IP 149段 很稀有的A段""体检报告这个仅供参考，库没更新"。所以准确表述是：**官方与多家测评称其为 Sky 段双 ISP 住宅 IP，公开路由显示为 Cogent 伦敦节点**。如果你对 IP 属性特别较真，先买月付自己上 ipqualityscore、scamalytics 查一遍再决定要不要年付，这个顺序比什么都稳。
